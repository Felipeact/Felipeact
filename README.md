## What I actually do

Most of my code starts as a real operational problem. I spend my days coordinating a multi-technician field-service operation — intake, dispatch, SLA windows, invoicing, parts — and I've spent the last few years turning the painful parts of that work into software.

That combination is the whole point of my profile: I'm a developer who has *lived inside* the workflows that field-service, logistics, and trades platforms are built to serve. I know what breaks at 4:55pm on a Friday when a dispatch window is about to blow, because I've been the person fixing it.

**Currently:** building multi-tenant SaaS in TypeScript · finishing a Diploma in Computer Systems at BCIT · open to full-stack developer roles in Metro Vancouver or remote.

## Featured work

### 🧰 Stockvio — Multi-tenant inventory & field-service platform

A production-shaped SaaS backend with two native clients on top of the same REST API. This is the project I'd point at first.

- **Multi-tenancy done properly** — company-scoped data isolation, role-based access control, JWT access/refresh rotation
- **Billing** — Stripe checkout, customer portal, and webhook reconciliation
- **AI assistant** — in-app assistant built on the Anthropic Claude API
- **Exports & storage** — CSV/XLSX/PDF generation, pluggable file storage (local · S3 · Cloudinary)
- **Two clients, one API** — a Qt6/C++ desktop app and a Flutter mobile app with barcode scanning and truck-stock workflows for technicians in the field
- **Shipped like it matters** — GitHub Actions CI/CD, Jest + Supertest coverage, Docker, deployed on Railway

`TypeScript` `Express 5` `Prisma` `PostgreSQL` `Qt6/C++` `Flutter` `Docker` `Stripe`

[**API & backend →**](https://github.com/Felipeact/inventory-system-api) · [**Qt desktop client →**](https://github.com/Felipeact/InventoryQtApp)

- Price and expense catalog backed by Prisma/PostgreSQL

`Next.js 16` `React 19` `TypeScript` `Prisma` `PostgreSQL`

[**Repository →**](https://github.com/Felipeact/MarcoEletric) · [**Live site →**](https://marco-eletric.vercel.app)
